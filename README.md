# Limzo 🦎

**The Telegram bot that makes group chats worth coming back to.**

[Limzo](https://limzo.com) turns everyday Telegram group activity into shareable public stats pages, member levels and badges, weekly highlight posts, and smart anti-spam moderation — all from one bot, free to start.

## What Limzo does

- 📊 **Public stats pages** — every group gets a live page at `limzo.com/s/<group>` with leaderboards, activity charts, quotes, and awards members actually share
- 🏅 **Levels, badges & achievements** — XP from karma (helpful replies, reactions earned), six badge tiers, nine collectible achievements
- 📬 **Weekly highlights & admin reports** — one auto-post recap for the group, a private web report for admins with a 13-week engagement trend
- 🛡️ **Smart moderation** — scam-message detection, newcomer captcha, fake-admin impersonator guard, link safety scan, `/warn` member warnings with automatic enforcement, an optional language lock, and a cross-group network shield
- 🎮 **Mini-games** — daily quiz, word race, guess-the-stat, counting chain, hangman
- 🌍 **13 languages** — bot, Mini App, and the full limzo.com site: en, ru, es, pt, id, tr, fa, it, ar, hi, vi, am, ms

## For developers

- **MCP server** — read-only public group stats for AI assistants: [`limzo-mcp`](https://github.com/LimzoCom/limzo-mcp) (`npx limzo-mcp`) or direct streamable HTTP at `https://limzo.com/api/public/mcp`
- **Public API** — [docs](https://limzo.com/docs/) · [OpenAPI](https://limzo.com/api/public/openapi.json) · [llms.txt](https://limzo.com/llms.txt)
